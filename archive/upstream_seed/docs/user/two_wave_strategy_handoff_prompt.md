**漂移分类必须建立在已识别的两个完整波形上。**

下面是可解释的候选基线，不是唯一指定公式：

\[
x_j=a+bt_j+wI_j+e_j,\qquad w>0.
\]

其中 \(x_j\) 为已确认拐点的对数价格；\(I_j\) 在高点取1、低点取0；\(b\) 是共同漂移速度；\(w\) 是上下两条平行边界的距离；\(e_j\) 是拟合残差。对上述五个拐点拟合后，可定义：

\[
D=\frac{b(t_{L_2}-t_{L_0})}{w}.
\]

它表示两个周期内整体漂移了多少个通道宽度。可以同时记录：

\[
E=\frac{\sqrt{\operatorname{mean}(e_j^2)}}{w}.
\]

请检查该模型的适用性和退化情形。若宽度非正、过小或拟合无效，应输出无效状态；不能取绝对值强行修补成有效趋势。
