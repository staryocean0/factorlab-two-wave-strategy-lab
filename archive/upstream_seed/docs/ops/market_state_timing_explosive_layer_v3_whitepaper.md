## 结论

研报/论文候选中，只有FDA“速度与加速度同向”机制通过了同职责替代门。止损再入场、
无约束FDA趋势、ETF成交量/份额和DTW均未替换现版：前两者扩大责任或跨期退化，后两者
缺少完整长期PIT数据或公式自由度过高。

V3不新增状态机，不改变反弹生命周期，只把暴跌反弹入口从拟合的四根K线路径效率
阈值改为：在弧线父事件开始时，严格前序的因果局部二次曲线端点速度和加速度都为正。

```text
recent_down = 0 < bars_since_completed_W12_W24_down <= 14
fda_up      = velocity_P48_over_4(t-1) > 0 AND acceleration_P48_over_4(t-1) > 0
R           = registered_arc_lifecycle IF recent_down AND fda_up AT parent_start
TC          = FDA_true_channel(P48 -> P96, opposite_rail_exit)

RU = R
TU = (TC == up)   AND NOT R
TD = (TC == down) AND NOT R
```

## 为什么不是参数峰

W12来自P48基准尺度的固定1/4导数窗，不读取审计期或外部期选择。邻域只作反证：W8、
W10、W12、W14在开发、重复审计、外部验证三段全部为正；W16外部期转负。因此研究结论
不是“窗越大越好”，而是P48内部短导数窗存在有界稳定带，W12位于公式锚点。

## 同职责事件归因

2009—2020年，V2与V3有140个重叠事件，其净价值完全相同；V2独有19个事件合计
+0.0650，V3新增109个事件合计+0.6566。增益来自补到同形态的暴跌反弹，而不是延长
重叠事件、改写出场或偷取P48→P96通道生命周期。

图形审计显示新增主增益路径均为下跌第一腿后的加速上拐；最大负差路径也保留在证据图
中。2020年V3反弹桶轻微为负，说明该门不是逐年必胜规则；但2009—2020有11年为正，
三段账户与夏普没有出现结构坍塌。

## 替换结果和代价

暴跌反弹年均净对数价值从 `+0.0507/+0.0578/+0.0122` 变为
`+0.1002/+0.1068/+0.0128`；第一层组合从 `+0.3976/+0.2438/+0.2869` 变为
`+0.4475/+0.3275/+0.2929`。第一层夏普三段从 `1.35/1.05/1.29` 提升为
`1.52/1.45/1.33`。

代价不能隐藏：开发期第一层最大回撤由26.28%升至28.22%；重复审计由25.08%降至
18.43%，外部期保持16.06%。因此V3是风险调整后和跨期能力更强的第一层，不是所有
单项指标都严格占优。

## 外部期漂移诊断补充

V3在2021—2026对V2的增益很小，但这不能只看区间总收益就判成过拟合。将完成事件
按 `1—12 / 13—24 / 25+`根K线拆开后，`25+`持续反弹的单笔净对数价值为
`0.02762 / 0.03010 / 0.02768`，跨期极稳定；年机会供给却从 `5.56`次降到
`2.67`次和 `1.64`次。外部期还丢失了审计期 `13—24`根过渡事件的正价值。

因此当前裁决是：参数过拟合不是主因；机会结构改变是主因，中等生命周期能力漂移是
次因。事后生命周期不能被当成预知信号。本轮对五类低自由度修复的挑战都显示：
若为了2021—26反向设门，必然明显伤害2009—20的真反弹。所以修复评价工作流而不改策略公式。
