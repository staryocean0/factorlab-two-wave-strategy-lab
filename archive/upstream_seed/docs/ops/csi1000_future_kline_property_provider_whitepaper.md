# CSI1000未来K线属性Provider白皮书

本设施只正式化已经获得回顾性证据的三类未来属性：实现方差、close路径范围、1分钟相对5分钟的总路程噪声膨胀。粗路径效率、方向和策略收益明确不支持。

Provider按调用者给出的历史训练前缀拟合标准化Ridge，不维护一个暗含未来数据的全局模型。输出为`KlinePropertyForecastCard`，包含均值与q10/q50/q90。分位数来自训练残差正态近似，只是研究不确定性视图，不是风险保证。

回顾性逐年证据中，未来RV、range和噪声膨胀均通过；粗路径组织度无证据。正式化只表示可复用研究基础设施ready，不授予LAT/IIR参数、交易门、路由或生产权。

五位一体和权限以机器合同`csi1000_future_kline_property_provider@1.0.json`为准。
