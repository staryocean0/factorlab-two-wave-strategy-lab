# CloudRidge 属性基础设施

CloudRidge 属性基础设施把云脊指数的底层 K 线属性从具体策略里提升为公共数据面。它只回答两件事：某个属性是什么意思；这个属性及其多周期均线数据在哪里。它不把任何属性直接升格为生产买卖点或风险信号。

## 权威产物

当前权威目录：

```text
output/cloudridge-attributes/current/
```

主要文件：

| 文件 | 用途 |
|---|---|
| `cloudridge_attribute_dictionary.csv` | 属性字典：含义、高低值解释、短窗读法、长窗读法、市场结构读法、公式摘要、来源模块和注意事项。 |
| `cloudridge_attribute_panel_1d.csv` | 日线属性时序面板：每个交易日一行，含 BDCI、BCI、WBI、PWBCI、DII、JRR、lag、波动、路径效率和12个论文原式EWMA核逐日毛收益。 |
| `cloudridge_attribute_ma_panel_1d.csv` | 属性多周期均线面板：默认 MA20/50/100/200/300/400/500。 |
| `cloudridge_attribute_manifest.json` | 产物清单：数据源、最新交易日、窗口、列数和图形路径。 |
| `plots/*.png` | 核心属性及 MA100/MA300/MA500 的快速查看图。 |

重建命令：

```bash
PYTHONPATH=src uv run python scripts/build_cloudridge_attribute_infrastructure.py
```

默认优先使用最新 5m 云脊 DataHub 导出，并按交易日取最后一根 K 线聚合成日线；若该文件不存在，则回退到旧日线 confirmed 导出。可以用 `--source` 指定任意云脊 levels CSV。

## 属性族读法

属性简介不是生产信号。它的目标是帮助 AI 和研究者从 K 线属性值变化中读出市场结构：短窗看最近行为，长窗看底层状态，最后再决定是否能进入某个策略的事件前验证。

| 属性族 | 短窗读法 | 长窗读法 | 市场结构读法 |
|---|---|---|---|
| `bdci` | 20/50 日抬升表示最近方向切换减少；快速回落表示短线涨跌互相打断。 | 200/300/500 日高值说明长期单向化，趋势惯性和拥挤交易可能同时存在。 | 只看方向切换，不看幅度；回答“有没有连续方向”，不回答“方向够不够强”。 |
| `bci` | 最近上涨日/下跌日数量投票；短窗转弱说明局部承接变差，但不说明幅度。 | 长窗 `bci_upshare` 偏高表示长期上涨日占优，可能积累顺风路径和获利盘。 | 颜色结构，不是力度结构；长期偏多后若 WBI/lag 断裂，可能成为流动性踩踏燃料。 |
| `wbi` | 最近上涨幅度和下跌幅度谁主导；从正转弱比 BCI 更能说明卖压有实际幅度。 | 长窗仍强而短窗转弱，常见于大周期尚未完全坏、局部流动性先断裂。 | 净方向压力表；比 BCI 更接近真实推动力，但仍是状态，不是未来收益标签。 |
| `pwbci` | 判断颜色偏斜是否伴随路径强度，过滤“上涨日多但每根很弱”的状态。 | 长窗描述长期颜色偏斜是否带有路径能量，更适合趋势许可或反卖出保护候选。 | 把数量投票和路径强度结合；`path_rank` 是历史秩，不能当绝对温度。 |
| `dii` | 对短期强位移敏感，适合描述行情是否已经打出方向冲量。 | 描述大周期是否存在持续净位移和路径能量。 | 解释力强但容易混入已经发生的行情结果；必须用事件前可见值验证。 |
| `jrr` | 抬升表示强 K 线后快速反向变多，滤波跟随更容易遇到假突破或急反。 | 长期高值说明行情连续性差、反转成本高。 | 适合描述滤波失效和暴跌后反弹/再入场环境；含波动秩，不能包装成独立领先因子。 |
| `lag_autocorr` | `lag1` 看隔日延续/反向修复；`lag4` 粗略观察一周节奏是否延续或反杀。 | 长窗 `lag4` 偏低常表示周内方向性缺失，上涨和下跌互相打断。 | 描述市场行为的时间记忆；不说明方向，但说明方向发生后能否被接力。 |
| `volatility` | 短窗抬升表示行情已经活跃或切换，常和暴跌同步。 | 长窗低波动可能表示市场钝化、控盘或成交结构更稳定；高波动说明冲击更易放大。 | 活跃度和冲击放大器，不是方向；不能用暴跌后的波动抬升反推暴跌前开门。 |
| `path_efficiency` | 抬升说明最近行情走得更直；回落说明同样波动中来回抵消更多。 | 长窗高效率叠加强 BCI/WBI 可能表示长期同向拥挤；低效率表示有波动但缺乏净方向。 | 形状指标，不带方向；回答“走得直不直”，必须和 WBI/DII 或 BCI 合读。 |
| `paper_ewma_kernel_return` | 1至60日核反应快，但必须在历史区间聚合后解读，不能根据单日正负路由。 | 100至500日只是同一原式的更慢EWMA信号尺度，不是第二估计窗。 | 逐日返回论文线性核的实现毛收益；不自带趋势/反转标签，也不授权第14工具动态调参。 |

## 后续策略使用方式

后续 AI 或策略开发应先读 `cloudridge_attribute_dictionary.csv`，再从属性面板或 MA 面板取列。研究“暴跌开门/关门”时，应使用暴跌起点之前已经存在的属性值或均线值，不得使用暴跌过程或暴跌之后的数据解释开门。

若要扩展到 60m、offset K 线或新增属性，先扩展 `src/factor_lab/cloudridge/attributes.py` 和测试，再重建 `output/cloudridge-attributes/current/`。论文EWMA核必须从[唯一渐进式入口](cloudridge_paper_kernel_multiscale_timeseries_workflow.md)进入；原论文是该入口Layer 0最高理论源头，不得在下游脚本里重新发明口径。
