# 项目级择时策略统一评价中台白皮书

当前唯一评价合同是 `market_state_timing_evaluation_platform@4.0`。
`market_state_timing_strategy_stage_evaluation@1.0` 和
`market_state_timing_evaluation@1.0` 是组件，不是第二套中台。

## 1. 它要解决的不是“谁收益高”

本中台属于项目级多空择时基础设施，不属于 Risk-Off V62、滤波择时或任何单一策略。
它回答四个问题：

1. 这一时期市场实际提供了多少上涨或下跌机会；
2. 策略抓住、部分抓住、漏掉了哪些机会，又假认领了哪些仓位；
3. 弱期来自行情供给减少、工具架构不能表达、工具族内需要路由，还是当前参数失配；
4. 当前结果只是已注册候选中的好结果，还是有新鲜期证据支持的稳定结果。

公共入口是 `market_state_timing_evaluation_platform@4.0`。V4 把原来由适配器填写的聚合捕获比率
降为兼容信息，将事件级机会、候选×机会、责任仓和 `M/F/B/R` 作为权威证据。

## 2. 事件级供给与抓取

“市场有多少行情”不能由策略自己的信号反向定义。权威机会账本必须：

- 与被评候选信号无关；
- 上涨与下跌分账，不能对消；
- 每个事件有起点、极值、结束、幅度和 K 线数；
- 同一批候选面对完全相同的机会集合；
- 机会层只有 `verified / inaccurate / inconclusive`，没有策略业绩意义上的“通过”。

平台要求完整的候选×机会矩阵，由原始行重算：

- 已抓、部分抓取、漏抓幅度与事件数；
- 同向/反向责任 K 线；
- 首次可执行抓取时还剩多少机会；
- 事件内候选实现价值。

候选自己产生的每个责任仓另外记账。没有匹配同向真实机会的生命周期不得被漏掉，
必须报告其次数、损失和持仓时长。

机会账本仍是对“行情”的一种有尺度定义，不是无尺度绝对真理。因此应保留多个预注册阈值/尺度的
敏感性视图，但同一生命周期在多档重复受检时不得相加。

## 3. M/F/B/R 可执行价值守恒

在每个策略尺度上冻结仓位集、最小持有 K 线数、执行网格、签名买入/卖出成本和期末平仓，
然后计算：

1. `M`：该尺度下一切合规仓位路径的事后市场上限；
2. `F`：只使用本轮预注册固定候选所提议动作的事后工具族上限；
3. `B`：该期间事后表现最好的一个已注册固定候选；
4. `R`：当前固定候选或冻结动态政策的实际可执行净价值。

它们必须满足 `M >= F >= B >= R`，并逐行精确闭合：

```text
R = M - (M - F) - (F - B) - (B - R)
          工具架构     族内事后路由     当前固定参数
```

`M/F/B`全部是事后诊断，永远没有信号、路由、参数或生产权。`B-R≈0`也只能说明“当前候选
在已注册有界家族中接近当期最佳”，不能宣称全局最优。

从参考期 `0` 到评价期 `1`：

```text
ΔR = ΔM - Δ(M-F) - Δ(F-B) - Δ(B-R)
```

- `ΔM < 0`：同尺度市场供给下降；
- `Δ(M-F) > 0`：市场机会还在，但已注册工具族表达不了；
- `Δ(F-B) > 0`：同族动作有价值，但需要事前可实现的族内路由；
- `Δ(B-R) > 0`：家族内仍有更好固定参数，当前参数失配。

## 4. 过拟合和“已经最优”怎么裁决

这套总账能定位研究方向，但不能单独证明无过拟合。

- “市场供给是主因”要同时被事件机会幅度/数量下降与 `ΔM` 证实；
- “当前参数已匹配”只在已注册有界候选族内成立；
- “无过拟合”还需要规则冻结后才打开的真正未消费时期；
- 动态策略还要在同粒度块上对比绝对收益、买入持有超额、冻结静态超额、尾部损失和离散度；
- 盈利但跑输买入持有或冻结静态，仍是相对失败。

因此平台只能输出“当前证据下的问题所在”和下一步应研究哪一层，不能把回测包直接升格为生产策略。

## 5. 三层评价与组件边界

统一顺序不可跳级：

1. **机会层**：确认策略无关机会账本忠实；
2. **命中入场层**：从真实可执行入场时刻评价命中、召回和剩余空间；
3. **完整交易层**：只在有真实出场后评价收益、回撤、夏普、回吐和成本；
4. **路由反事实层**：只替换目标桶动作，桶外路径不变；
5. **跨期归因层**：用事件账本与 `M/F/B/R` 区分供给、架构、路由和参数。

| 组件 | 位置 | 责任 |
|---|---|---|
| 事件机会与 M/F/B/R | `factor_lab.market_state.timing_event_opportunity_attribution` | 原始事件重算、假认领、四层守恒与跨期根因 |
| 分尺度事后上限 | `factor_lab.market_state.timing_scale_oracle` | 同执行与签名成本的 M/F 可执行上限 |
| 三层研发评价 | `factor_lab.market_state.timing_strategy_stage_evaluation` | 机会、命中入场、完整交易 |
| 路由桶反事实 | `factor_lab.market_state.timing_evaluation` | 固定桶外路径后的动作价值 |
| 跨期匹配归因 | `factor_lab.market_state.timing_matched_attribution` | KNN/倾向匹配、平衡、Shapley、单位价值拆解 |
| 统一入口 | `factor_lab.market_state.timing_evaluation_platform` | 合同、证据门、持久化、哈希和报告 |

Risk-Off V62、冻结爆发桶、四小时下跌和滤波择时只是适配器/样板，不是中台所有者。

## 6. 当前可复现样板的结论

三个专项桶、不含 IIR 的样板在 2009—2020 已消费区间上显示：

- 2018—2020 相对 2009—2017 的实现价值下降，主要由同尺度市场供给下降解释；
- 四档方向 ZigZag 机会账本独立显示，年均机会供给下降约 24%—47%；
- 大幅机会的捕获能力整体没有同比坍塌，部分尺度还有改善；
- 在预先登记的 6 个 OLS 动作候选族内，2018—2020 的当前固定参数失配接近零；
- 2016 年更像工具架构缺口，2009/2014 在有界候选族内存在局部参数空间。

这些是追溯归因，不是新鲜泛化证据，更不是“策略没有问题”。详细证据见
[2026-08-13 三专项桶事件归因](evidence/market_state_three_specialist_no_iir_event_attribution_v1_20260813.md)。

## 7. 权限与黑箱

本中台只有评价权：信号、路由、参数和生产权全部为 `false`。
2021—2026 若为封印黑箱，只允许有一次性收据绑定的整段聚合评分；事件、单年、责任仓、路径、图形和
M/F/B/R 明细均被代码拒绝。中台对合同、原始账本、结果表和报告记录 SHA-256，并在持久化后再次语义重算。
