# 波动率三态识别器等预算嵌套优化 V2 白皮书

> 四层拆分：连续特征属于 Layer 2；三态切分、滞回和驻留属于 Layer 3b。
> 两者不再由同一个公共 API 同时输出；3b 不是长期底座且无生产权。

当前唯一识别器合同：`market_state_volatility_regime_recognizer_nested_v2@2.0`。
它吸收并取代默认参数 Battle `@1.0` 的现役入口权；Battle 只保留未调参家族赛的历史复现。

每个家族预注册12个参数身份，10家族共120次。2015作初始材料，2016–2020每年只用以前材料选家族冠军，然后盲测当年。2022–2024使用2015–2020冻结的最终家族参数，零重调。

## 冻结冠军参数

- 简单滞回：16根波动率、512根历史、1/3–2/3分位、1根确认、最小驻留4根。
- 简单分位：16根、512根历史、25%–75%分位。
- Bipower硬分桶：16根、25%–75%、jump 85%门。
- CUSUM：8根、`k=.25,h=3`。
- BOCPD：8根、hazard 32、max-run 128。
- RV-HMM：8根、快特征权重0.85。

当前只是回溯家族冠军排名，`fresh_oos=false`，不授予桶内策略、杠杆或生产权。
