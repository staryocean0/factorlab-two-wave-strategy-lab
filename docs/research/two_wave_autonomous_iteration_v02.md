# 两浪 H0 自主迭代协议与候选 v0.2（2026-09-05）

## 用户授权与研究状态

用户在本轮对话明确要求：由 AI 自主完成实现、历史重放、图形归因、自审与迭代，不把每个开发版本的人工盲审作为前置条件；候选成熟后再集中交给用户验收，并要求接管 GitHub 开始研究。本文件更新旧交接入口的开发顺序，不篡改原始提示词或旧实验记录。

允许没有真人标签时继续开发、测试、比较和审计。`independent_reference_count=0` 仅限制独立形态准确率/召回率的声明，不阻止研发。不伪造真人标注，不把 AI 自审变成独立真值。本轮不打开 H1/H2、收益优化、交易、生产注册；继续只使用仓库原始 2015—2020 开发数据，禁止重采样和取得 2021 年以后数据。

## 版本范围（真实数据候选结果出现前固定）

起点为 `46273ddace21769a7f73d8d8b627d77dbeb43e22`。保留 v0.1 识别器、规范、评价协议、历史结果和十五工具身份，全部不修改。新模块 `candidate_v02.py` 继承原有因果拐点/周期/生命周期，单独替代几何分类。新配置、结构与事件身份包含候选版本；波浪尺度 ID 不变。

比较三种预定方法，不搜索阈值：

| 方法 | 周期幅度条件 | 局部漂移速度差 |
|---|---|---|
| v01 | 原五点周期极差比 | 保留拒判 |
| detrended_width (A) | 完整周期所有 close 去共同漂移后的极差比 | 保留拒判 |
| drift_tolerant (B) | 同 A | 仅作属性；保留其余拟合、相位方向、宽度条件 |

A、B 沿用 v0.1 的共同线性漂移 b、模型宽度 w、D、E、方向容差、1.6 宽度比、0.75 斜率差、0.2 拟合误差和 0.5 漂移分类门槛。极值依然是原始价格反转，并未切换为去趋势波浪。对每个已确认完整周期，在其原始起止索引内计算 `z_i = log(close_i) - b*(i-origin)`，将两周期 `max(z)-min(z)` 比较。两个周期共享第三极值，均包含它。数据截止第五极值；第五极值之后的确认腿不用于拟合或宽度计算。

理由：原始周期极差混入漂移与时长；等宽匀速漂移不应仅因该混入被拒判。B 额外检验是否应将速度差与方向一致性分开；B 仍可能不适合目标，不能按覆盖率择优。收敛、扩张、相位相反和拟合失真没有被统一当成趋势。

新 schema 明确区分 `attributes`（诊断属性，包括旧规则触发）和 `rejection_reasons`（当前候选真正阻断分类的原因）。消费者不得继续假定 attributes 非空就等于 uncertain。旧输出含义不改变。

## 本轮固定执行与审计设计

1. 跑全仓库测试和冻结包验证；本地测试仅说明本地实际具备的文件，远端完整测试单独归属提交。
2. 14 个原始视图，三个固定反转门槛 .008/.010/.012，各重放 v01/A/B；不因某组结果不好而丢弃。
3. 比较完整五点成员、确认时钟与几何首越界事件。分类不同可以改变越界的同向/反向关系标签，但边界数值、首次越界方向和时间应不变；这不是第三浪统计或交易回测。
4. 每个重放保存实际逐根发出的事件摘要，与最终事件逐条摘要对照；独立重放固定前缀 `min(1600,N)` 和 `N//2`，比较 pivots/cycles/structures/events。合成短序列独立重放每个前缀。不得称真实长序列已独立重放每一个前缀。
5. 在 .01 上对各视图施加固定 `exp(1e-5*sin(i*sqrt(2)))` 因子到同根 OHLC，不改变顺序、时钟或源文件。按五个极值原始索引和相位做严格匹配，分别报告未匹配数量、匹配上的分类变化、首越界时间/方向变化。严格匹配不能替代近邻匹配，更不能称为准确率。
6. 图集按结构来源的 SHA-256 排序选择，覆盖原明确/原拒判、A 新明确/A 新拒判、B 额外明确等桶；每桶最多两例，不依图形美观和收益选择。保留空桶。图只画到结构确认时；原始完整数据与五点/指标另存 JSON，图形抽样不是独立市场标签。
7. 原始源文件逐一校验 manifest；运行前后校验源代码与协议哈希。日志打印每组摘要、总摘要和少量可重画的审计案例，完整事件与图集存工件。

## 内部判据与本轮不可宣称的事

硬性门：新增测试、完整仓库测试、源数据/代码不变、上述前缀检查、候选与基线成员和几何事件对齐全部通过。规范化正例应识别，反例应保留明确拒判原因；强漂移且无原始反转不得造浪。数值边界允许记录浮点容差，不允许按市场结果移动阈值。

真实数据同时报告总数、明确率、拒判联合原因、确认延迟、版本转移、图形失败和扰动变化。明确率不是准确率。包络覆盖 100% 是取历史极值的构造性质，不是拟合优度或预测能力。重复产品、跨尺度和相邻结构不独立，不计算伪独立 CI。不把旧的 2015—2020 开发区间改称全新样本外。

本轮是有边界的测量修正实验，不是完整形态验收。即使硬性门通过，也只能表示候选值得继续研发；只有充分的真实图形审计、失败机制消解和稳定性检查后才能标为 ready_for_user_review。尚未成熟时继续由 AI 研究，不请求用户逐版本标注。不按更高覆盖或更好未来收益宣布 A/B 为胜者。
