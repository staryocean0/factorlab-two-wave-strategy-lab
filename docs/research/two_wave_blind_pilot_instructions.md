# 第一次盲审：只处理一个既定窗口

这份材料帮助明确什么形态符合你的“两浪父结构”概念，不是已经完成的验收集。产品为供应商 `30m_offset_15`，反转尺度使用固定 log-close `.01`；不要把 30 分钟直接等同于波浪尺度。两个完整周期须有五个交替极值，不是两条单向腿。

## 先选参考模式

在线参考使用 `pilot_online_blind.html`；若已经看过这个样本的后续价格或算法结果，请保留为离线/非独立意见，不将其标为盲在线真值。在线文件物理上只含 #0—#978 的原价，不含任何算法拐点、边界或分类。文件隔离不能消除审查者此前的记忆。

离线参考使用 `pilot_offline_blind.html`，并先勾选“完整历史图回看”。它比核心末端多包含 128 根后文。两位独立审查者应分别完成同一模式的意见，不能先共享选点再说是独立标注。

## 操作

1. 下载后用浏览器打开 HTML。核心是原始序号 **723—978**。统一在线最终截断位置填 `978`；可从早向晚播放，另记最早认为足够确认的时刻，不回退后冒充首次判断。
2. 为看清核心，将起始 UTC 填 `2015-07-02T05:45:00+00:00`。核心末端为 `2015-09-01T02:15:00+00:00`；上海显示时间比 UTC 晚八小时。需要前文时可向前扩展视图。
3. 在原始 close 上选连续五个交替极值，填写低点/高点起算及父分类。第五极值应在 #723—#978 内，前四点允许在前文。没有合适两浪也可记录“完整审查后没有两浪”，不能为了交表强行造浪。
4. 保存每条标注后下载 JSON。只有确实检查了整个核心，才声明完整审查；声明前应将视图范围还原为核心，避免把前文也计入完整审查。离线图可临时把可见区间末端收回核心后声明，前面已看过的后文仍保持离线属性。
5. 记录判断理由、置信度和实际来源。现有 HTML 导出暂不含这些字段，使用下方准备命令补空表后由实际审查者填写，或将原导出连同真实说明一起交回。

```bash
python scripts/reconcile_two_wave_annotations.py --prepare-review your_export.json --output cloud_results/your_review_preparation_v1
```

请保留原导出及所有后续版本。准备程序不会代你确认“真人、独立、未见未来”等声明。

若直接在对话里给出首轮意见，可以按这个结构描述：

```text
模式：离线 / 在线前缀（说明是否已见后续或算法）
五点原始序号：
相位：低点起算 / 高点起算
父分类：震荡 / 上涨 / 下跌 / 不确定
理由：
置信度（0—1）：
两浪速度不同或原始振幅不同，是否仍符合你想识别的结构：
核心是否全部审查：
```

首轮零散意见能帮助明确模型含义，但不能直接估计全量召回、假阳性或宣告验收通过。后续完整流程见 `two_wave_annotation_adjudication_workflow.md`。
