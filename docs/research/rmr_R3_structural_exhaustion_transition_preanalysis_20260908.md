# R3 preanalysis — Structural exhaustion / transition reversal risk

Date: 2026-09-08  
Identity: `R3_structural_exhaustion_transition_stage1_v1`

## Question

A parent structure is still directionally displaced, but its quality begins to deteriorate before a clean opposite structural break has occurred.

Ask:

> **Can causal deterioration of the parent structure identify rising transition/reversal risk before a simple direction flip?**

This lane is different from R1. R1 assumes the parent is still intact and asks whether a lower-scale counter-move is temporary. R3 asks whether the parent itself is already losing integrity.

## Coordinate definition

- parent scale: one predeclared M0 structural scale;
- current state: directional parent already established by completed/published structure only;
- deterioration object: change in parent quality between consecutive published structures / waves;
- positive transition outcome: parent-direction failure or opposite parent-level qualification before another comparable same-direction extension;
- negative outcome: another parent-consistent extension first;
- unresolved / ambiguous path: censored.

Exact M0 field mapping is bound by metadata/schema inspection before outcome computation.

## First-pass deterioration candidates

At most three low-capacity objects, chosen from existing M0 measurements only:

1. `translation_decay` — directional drift/progression weakens;
2. `structure_quality_decay` — overlap/roughness rises or efficiency falls;
3. `combined_deterioration` — a fixed small combination of 1 and 2 if both component directions are predeclared before outcomes.

No HMM, Koopman, neural regime model or large state-space search in Stage-1 v1.

## Hypotheses

H1. Parent deterioration predicts transition/failure beyond current parent move magnitude or age alone.

H2. The useful object should have an interpretable direction: more deterioration should not switch meaning arbitrarily across 2019 and 2020.

H3. If only a complex combined object appears positive while simple deterioration components are unstable, the lane remains `mixed_hold` rather than progressing.

## Evidence roles

- BUILD: 2015–2018 consumed development material;
- chronological check: 2019–2020, not fresh;
- post-2020 unopened for this broad screen.

## Progression condition

Progress only if at least one predeclared deterioration object:

- has adequate event supply;
- adds stable incremental information beyond simple parent magnitude/age baseline;
- has coherent direction in both chronological check years or a clearly predeclared pooled gate with no severe sign reversal;
- is not merely a re-expression of the outcome boundary itself.

## Forbidden rescue

Do not after results:

- search dozens of state variables;
- introduce deep latent regime models;
- use future extrema to label deterioration;
- tune state-count or transition thresholds;
- keep only one favorable year/offset/direction;
- select by PnL.

If the simple structural deterioration premise does not survive Stage-1, close this identity before considering a new theory-driven regime model.
