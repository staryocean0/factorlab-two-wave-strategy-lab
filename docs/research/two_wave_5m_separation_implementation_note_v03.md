# v0.3实施说明与试验记录

主要目标是5m_offset_0；其余5m相位为敏感性，一分钟只作对照。主协议two_wave_5m_separation_protocol_v03.md已在641a911提交中先于本轮实测结果记录。

C是v0.2 A的追加式方向旁路，不改写A事件/几何及原v0.1。方向记录另有ID、schema、config_hash和明确源结构关联；A边界不因C方向明确而获得交易可用性。

在读取本轮市场结果前，合成扩张案例暴露“只限制相邻同相位位移”不足以排除累计相位迁移；C震荡判断采用多数相位三点总跨度和另一相位两点跨度均不超过0.5个拟合宽度，而非只检查相邻差值。初次该测试失败，修正后25项新性质测试均通过；这是构造测试修正，不是按市场结果调参。

研究容器为Python3.13，仅作为补充分析，仓库正式支持的Python3.11全仓库测试和全量实验在新增Actions执行。原始14个Parquet经私有Actions工作副本和本地SHA256逐个核验，无重采样和新增行情。工作副本run33954426185成功；补充读取依赖的一次YAML裸冒号错误导致run33954558522失败，修正后run33954719000成功；这些基础设施运行不是形态识别研究通过证据。

初始本地频段分析两次因工具时限中断，部分输出保留，不作为完整研究。完整本地frequency_r3在未改公式和切点下执行。外部AI没有提供具体ER公式和窗口，故不声称原样复现；同根数与同起终点比较可能方向相反，所有口径都需报告。

执行命令：python scripts/run_two_wave_frequency_study.py --stage all --output <new-empty-output-directory>。脚本输出原始配对数据、各年度与相位的描述结果、固定分块bootstrap、非重叠窗口状态转移和会话内打乱控制。置信区间估计的是每日ER标准差配对差值之均值，不是样本外正确率。

图集选择主5m/.01下各类两个最小SHA256结构ID，截断至结构确认时，属于开发审计而非人类真值。C目前未自动宣告成熟；不能用覆盖率更高替代形态验收。H1/H2、收益择优、注册生产和真实交易均未开放。
