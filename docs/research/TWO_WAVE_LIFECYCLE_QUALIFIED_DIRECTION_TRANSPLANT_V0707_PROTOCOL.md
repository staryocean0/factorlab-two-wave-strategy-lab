   - D1 label;

## 6. Frozen v0.6.25 contract

The historical v0.6.25 rule is reused byte-for-byte semantically:

1. if D1 is `range`, `uptrend`, or `downtrend`, output D1 exactly;
2. only if D1 is `uncertain`, compute the frozen four-view v0.6.23 erosion-consensus Huber state;
3. if consensus is not unanimous decisive, remain `uncertain`;
4. if unanimous decisive, compute the frozen consensus margin to the historical state boundary;
5. rescue only when `consensus_margin >= 0.10` (inclusive, using only the existing floating-boundary epsilon already present in v0.6.25).

Forbidden changes include averaging support scores, majority voting, a second margin, an offset-specific threshold, a lifecycle-status threshold, or any new direction feature.
