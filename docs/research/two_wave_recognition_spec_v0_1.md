# 两完整波浪父结构识别规范 v0.1

状态：`recognition_specification_frozen_before_real_result_review`。本版在读取本识别器真实行情运行指标前写定；运行产物须记录本文件、评价协议、源码及配置的 SHA-256。它是第一阶段的可替换实现假设，不是用户已经指定的唯一数学定义，也不证明任何交易规律。改变定义必须产生新版本、说明原因并保留旧结果；不得看见结果后修改本版阈值或验收目标。

## 1. 目标、已知材料与边界

目标是在一个给定 K 线产品上，先识别两个连续、同尺度的完整实际反转周期，再描述其局部父包络的漂移。输出必须能够逐根审计“发生了什么、什么时候才知道、当时边界是什么”。

- 原始需求：`docs/user/two_wave_strategy_handoff_prompt.md`。
- 已提供：000852.SH 中证1000指数的 DataHub K 线产品，2015-01-05 至 2020-12-31，仅为 `development_material`；原始十五工具注册表及 Layer 1/2/3 契约。
- 缺项：独立人工波浪与父分类标签、历史图与截断图两套参考、真实市场形态验收结果。缺标签时结论必须是 `morphology_replication_not_yet_accepted`。
- 本阶段仅提供研究测量，不产生持仓、交易信号、期权选择或成交记录，不研究第三浪条件概率，不授予注册使用或生产权限。`tool_registry_v1_5` 及当前十五身份保持不变。
- 2021 年及以后行情禁止读取、下载、请求、推断或制造；2009—2014 缺失不能补造。2015—2020 不能称为新的样本外证据。

## 2. 数据、采样与尺度

输入至少含 `timestamp/open/high/low/close`，`volume` 可选。读取仓库已有 DataHub 产品及其完整产品身份，包括频率、偏移及实际 `export_frequency`；不在本地重采样。输入时间戳是有时区的 UTC **K 线结束时间**，上海显示时间和原始序列化时间只供审计。`daily_proxy_close1400/1430` 分别来自 60m/30m 每日抽取的单根 bar，只能解释为供应商代理视图，不能把其 OHLC 叫作完整日线 OHLC。

**bar-end 不等于实际信息可得时间。** 数据契约预检发现，当前可下载的 6 个 Parquet 的 `available_at` 统一为当日上海时间 15:30，早盘 bar-end 早于该时间；这些导出材料不能证明当年早盘已经实时提供相同行情。原字段必须保留，每个事件另存 `information_available_time = max(截至当前处理 bar 的 available_at；缺失行以 timestamp 代替)`。缺 `available_at` 的行标记 `bar_end_assumed=True`，明确这是一项理想同步假设。几何确认仍保留 bar-end 时钟，但“当时可得”审计须同时看信息时钟；前缀不变不等于历史 point-in-time 或可成交性证明。

检查时间严格递增、无重复、OHLC 有限且为正、`low <= open,close <= high`。异常不得默默排序覆盖或填价；拒绝无效输入并输出原因。休市不补 K 线，缺失量不填零；缺失价格不前向填充。时间间隔异常应报告，不能仅凭周末或休市推断数据缺失。

识别价格为 `x_i = log(close_i)`，几何时间轴为已接收 K 线序号 `i`。午休、隔夜与周末不增加虚构的序号间距。因此本版斜率单位为“每根实际 K 线的对数价格变化”，不是每自然小时变化。高低价用于显示与数据检查，不用于假设同根 K 线内极值先后。

| 配置 | 默认值 | 含义 |
|---|---:|---|
| `instrument` | `000852.SH` | 信号品种身份 |
| `timeframe` | 所选现有产品 | 与产品偏移、来源共同保存；不是波浪尺度 |
| `reversal_log` | 0.01 | 固定对数反转门槛，单一运行内冻结 |
| `drift_threshold` | 0.5 | 两周期累计漂移/拟合宽度的分类门槛 |
| `max_fit_error` | 0.2 | 无量纲五点拟合误差上限 |
| `direction_tolerance` | 0.15 | 同相位方向检查的无量纲容差 |
| `max_slope_disagreement` | 0.75 | 高低点漂移分歧上限 |
| `max_width_ratio` | 1.6 | 相位宽度、两周期振幅、包络/拟合宽度的形态检查上限 |
| `min_width` | 1e-8 | 允许的最小正对数拟合宽度 |

同尺度仅指同一冻结的反转规则与参数产生的波浪，不要求两浪等长等幅。时长和振幅差异要记录，不另设事后筛选容差。ATR 缩放、去趋势周期、固定尺度倍数关系均不属于本基线。

## 3. 原价反转、完整周期与相位

选择**原价格实际反转**；对数变换单调，保持实际价格的升降次序。上涨搜索阶段保存当前最高收盘点，当前收盘较它回撤至少 `reversal_log` 时才确认高点；下跌搜索阶段对称。严格更高/更低才更新候选，等价平台保留首次极值时刻。固定门槛在流式处理中不回溯更新。

启动时方向未知。首个通过门槛建立的初始化极值标记 `left_censored`，不据它构造可验收周期或结构；初始化状态、当前候选与已确认拐点分开保存。末端未确认的候选不能用作已完成周期。

对于 `x(t)=bt+A sin(ωt)`，当 `b>Aω` 时原价格严格上涨。尽管去掉漂移仍有周期，本版应输出无已确认完整两浪或不足两浪，不强行造浪。这种未覆盖情形计入可识别性描述。

完整周期为三个相邻、交替确认点，例如 `L0 → H1 → L1`。两个连续完整周期共享中间同相位端点，形成 `L0 → H1 → L1 → H2 → L2`；高点起算对称。两条单向腿只是一周期。

双相位均保留：每次新增有效确认点，检查最近五个连续有效确认点。每个窗口输出确定的成员拐点、两个周期和相位，不按未来效果挑选。周期通过成员三点去重；结构通过尺度、相位与成员五点去重。不同相位和相邻重叠结构不是统计独立样本。

## 4. 包络、漂移与分类

只使用五个已确认拐点及其首末**发生时刻**之间的历史收盘序列。令 `t` 为相对首点的 K 线序号、`I` 在高点为 1、低点为 0，对五点拟合：

`x_j = a + b t_j + w_fit I_j + e_j`。

模型须满秩、系数有限、时间跨度正、`w_fit > min_width`；不满足时输出无效原因与 `uncertain`，禁止取 `abs(w_fit)` 修补。定义 `D=bT/w_fit`、`E=sqrt(mean(e_j²))/w_fit`，其中 `T=t_4-t_0`。不把屏幕角度或任意滚动回归窗口当作两浪识别。

拟合边界 `a+bt` 与 `a+bt+w_fit` 不保证覆盖整个周期。另用首末极值之间所有 `x_i-bt_i` 的最小、最大值定义冻结的实际收盘包络截距，包络宽度为 `w_env`。同时保存五点拟合边界覆盖率、实际包络覆盖率及两个宽度，明确 `D/E` 仍以 `w_fit` 归一化。实际包络对构造区间 close 应达到 100% 覆盖（允许浮点误差）；这不承诺包住全部 high/low，更不证明未来会持续。

附加检查先对高点和低点分别拟合 `x=offset+slope*t`，各自无量纲漂移为 `slope*T/w_fit`。含三个同相位点的一侧称多数相位；其两段位移分别除以 `w_fit`，两段局部斜率分别乘 `T/w_fit`。两个三点周期的振幅分别为该三点 log-price 最大值减最小值。以下任一情形出现均列为属性并输出 `uncertain`：

| 规则 | 属性 |
|---|---|
| `E > max_fit_error` | `poor_pivot_fit` |
| 独立高低点线在首末时刻的宽度任一 `<= min_width` | `phase_lines_cross_or_collapse` |
| 首末宽度的 `max/min > 1.6` | 末端更宽为 `expanding`，否则 `converging` |
| 高低点无量纲漂移分别显著高于 +0.15、低于 -0.15 | `high_low_direction_conflict` |
| 多数相位两段位移/宽度分别显著正负相反 | `within_phase_direction_conflict` |
| 高低点无量纲漂移差绝对值 `> 0.75` | `phase_slope_disagreement` |
| 多数相位两段无量纲局部斜率差绝对值 `> 0.75` | `uneven_phase_drift` |
| 两周期振幅 `max/min > 1.6`，或比例无效 | `cycle_amplitude_change` |
| `w_env/w_fit > 1.6` | `large_envelope_expansion` |

原始诊断数值一并保存；不把“先升后降、总斜率恰好为零”直接叫作稳定震荡。较小收敛扩张仍可从宽度数值看到；本版命名形态标记由上述固定门槛触发。

主分类为 `range/uptrend/downtrend/uncertain`。有效且通过拟合及形态一致性检查后，`D > 0.5` 为上涨，`D < -0.5` 为下跌，其余为震荡；无效、拟合误差超限或显著方向冲突等拒判原因逐条输出。收敛扩张属性另存，不能靠隐藏拒判提高准确率。阈值只是本版候选，不是已由真实标签证实的最优值。

## 5. 因果时间、生命周期和边界事件

每根收盘到达后，先用旧结构此前有效的冻结边界检查当前几何破坏，再进行当前拐点确认和新结构建立。不能使用破位后的价格放宽旧边界、取消旧事件。

- 拐点逻辑 `occurred_at`（代码 `occurrence_time`）：极值所在 K 线结束时间；逻辑 `confirmed_at`（代码 `confirmation_time`）：第一次达到反转门槛的 K 线结束时间。另存 `information_available_time`，不得把几何确认时刻说成已证明的真实历史可用时刻。
- 周期完成时刻：末拐点的确认时刻；两浪结构确认和首次分类时刻：第五拐点的确认时刻。
- 几何样本截止第五拐点发生时刻；第五点发生到确认之间的确认腿不纳入拟合/扩大包络。
- 首次分类时需检查当前收盘是否已经越界，单独记录“确认时已越界”。这不是先前可交易的历史突破；本阶段不回填信号或成交。
- 后续突破使用冻结斜率和截距外推，收盘严格越过上沿或下沿时记录方向、当时边界及原因。斜线随时间抬升而横盘跌出也属于几何越界，不等于已经证明价格趋势反转。
- 几何首次越界可结束结构的几何监测；结束原因和时刻追加记录。新结构具有新 ID，不替换旧结构或重置其原始起点。未结束结构遇到同相位后续完整周期，累计浪数从原来的 2 继续增加。样本尾部仍有效的结构记为观察尚未结束，不能当作突破。
- 已确认事件只追加；若将来支持重估，须新增版本并写明生效时刻。本版几何参数冻结，不做事后重拟合。事件类别为 `pivot_confirmed/cycle_confirmed/structure_confirmed/structure_cycle_confirmed/structure_breakout`；首次突破令几何状态 `geometry_alive=false`、浪数冻结。样本末存活对象在快照标记 `right_censored`，不伪造结束事件。

`signal_at/executable_at/position_owner` 为后续阶段接口，本版保持空或明确未实现。指数 bar-end 之后的下一条指数行情不是已验证的交易品种成交机会。几何生命周期、未来持仓生命周期与归属是不同对象；同向几何突破不自动产生平仓、反手或跨级别交接。

## 6. 逻辑输出与审计字段

允许采用嵌套 JSON 或规范化表，但下列信息应能够直接读取或经确定的 ID 关联取得；具体名称映射应在运行说明中列出。

| 记录 | 必要信息 |
|---|---|
| 运行 | 数据路径/产品身份/哈希、品种、频率、尺度 ID、完整配置与配置哈希、源码/规范/协议版本、输入范围与行数、数据异常 |
| 拐点 | ID、类型、bar 序号、原价/log价、发生时间、确认时间与延迟、信息可得时间、初始化截断标记 |
| 周期 | ID、三个成员 ID、相位、发生区间、确认时间、振幅、时长 |
| 结构 | ID、五点与两周期成员、相位、原始起点、确认时间、版本/生效时间、累计波数 |
| 几何 | `a/b/w_fit/w_env/D/E`、拟合有效性、两种覆盖率、同相位方向诊断、形态属性、主分类及拒判原因 |
| 事件 | 事件 ID/类型、所涉结构及版本、几何确认/生效时间、信息可得时间、触发收盘与边界、确认时已越界、浪数增加或几何结束 |
| 流式状态 | 候选拐点、已确认对象数、初始化/不足两浪/可识别状态、截至当前时刻的有效边界 |

代码中 `width` 对应 `w_fit`，`envelope_width` 对应 `w_env`，`nominal_coverage` 对应拟合线覆盖率，`envelope_coverage` 对应实际包络覆盖率。几何有效 `valid=true` 不代表分类一定明确：形态检查可使其仍为 `uncertain`。

可视化须支持产品/尺度/时间选择和截断或逐根播放；显示原始 OHLC、候选/确认点、极值与确认时刻、周期编号、结构 ID、冻结通道和分类依据。把极值位置标记、bar-end 理想确认和信息可得时间明确区分。若播放器只按 bar 序号截断，必须显示其为理想同步重放，不能称真实历史实时可得。盲标注导出隐藏算法点、分类及边界，审查视图再叠加算法；导出接口不能让算法标签直接进入人工真值。
