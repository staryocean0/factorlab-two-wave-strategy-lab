# R1 preanalysis — Cross-scale pullback inside an intact parent trend

Date: 2026-09-08  
Identity: `R1_cross_scale_pullback_stage1_v1`

## Question

A parent structure is already directionally displaced. A lower-scale move then develops in the opposite direction.

Ask:

> **For counter-moves of comparable severity, does causally available parent integrity add information about recovery before parent failure?**

This is the mechanism version of “buy the dip in an uptrend / sell the rally in a downtrend.” It is not yet a trading rule.

## Coordinate definition

- parent scale: one predeclared coarser M0 structure scale;
- lower scale: one predeclared finer causal scale;
- parent state: continuous directional integrity, not a tuned trend bucket;
- deviation: completed opposite-direction lower-scale move;
- recovery: price first recovers the lower-scale move origin / predeclared parent-consistent recovery boundary;
- failure: price first violates the predeclared parent structural boundary;
- unresolved/ambiguous path: censored.

The exact scale pair and available field mapping must be bound by metadata/schema inspection **before** any R1 outcome computation.

## First-pass baseline and candidate budget

Exactly three comparison objects at most:

1. `counter_move_severity_only`;
2. `parent_integrity_only`;
3. `parent_integrity_plus_counter_move_severity`.

Parent integrity may use only a small continuous set already available from M0, prioritizing:

- directional drift / translation;
- overlap or phase consistency;
- path efficiency / roughness;
- parent width/scale for normalization.

No broad technical-indicator search.

## Hypotheses

H1. Opposite lower-scale moves inside stronger parent integrity have a different recovery-before-failure probability than equally severe counter-moves in weaker parent integrity.

H2. Parent state must add incremental information beyond counter-move severity; severity alone cannot be relabeled as “trend integrity.”

H3. Any effect should keep the same economic direction in 2019 and 2020 when learned/described on 2015–2018.

## Stage-1 evidence roles

- BUILD: 2015–2018 consumed development material;
- chronological check: 2019–2020, not fresh;
- post-2020 remains unopened for this broad screen.

## Progression condition

R1 is progression-worthy only if:

- event supply is not trivial;
- parent+severity improves the simple severity baseline on pooled 2019–2020 probability quality or preregistered first-passage separation;
- the parent effect has the same directional interpretation in both 2019 and 2020 or failure is explicitly attributed;
- results are not driven by one tiny scale/offset cell;
- causal timing and M0 event publication rules are preserved.

This is not a fresh-OOS or production gate.

## Forbidden rescue

Do not after results:

- search many scale pairs;
- tune a trend threshold;
- add RSI/MACD/moving-average filters;
- split by calendar year/month/event;
- change recovery/failure boundaries;
- select by PnL;
- use future-revised parent states.

Failure means close or hold this R1 identity, not add conditions until it works.
