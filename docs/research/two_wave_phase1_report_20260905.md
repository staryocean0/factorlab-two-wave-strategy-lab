## 2. 已实现的内容与明确边界

核心代码位于 `src/factor_lab/visual_structure/two_wave/`，拆分为数据检查、冻结配置、流式识别、几何分类、回放和人工标注评价模块。

- 使用原价格的 log-close 固定门槛反转；`.01` 为基准，`.008/.012` 只作预定敏感性比较。K 线产品与波浪尺度分开记录，不要求两浪等长等幅。
- 五个交替、已确认极值构成两个完整周期；高低两种起算相位均保留。首次初始化极值标为左侧截断并排除，平台同价取首次，末端候选不能充当确认点。
- 五点拟合 `x=a+bt+wI_high`，输出 `D/E`；另以首末极值之间全部 close 构造冻结包络，分别保存拟合宽度与实际包络宽度。确认腿不被纳入拟合以掩盖越界。
- 主分类为震荡、上涨、下跌、尚不确定；方向冲突、收敛扩张、漂移不均匀和幅度变化均保留具体诊断值及拒判原因。
- 结构拥有稳定 ID、成员周期、起点及年龄；新增滚动候选不重置旧结构年龄。先用旧边界检测当前破坏，再确认拐点和新结构。
- 保存极值发生、几何确认、信息可得时间；事件只追加。记录确认时已越界及之后首次几何越界，样本末存活结构保留右截断。
- 提供 JSONL 记录、总摘要、自包含 HTML 重放、盲标注导出、完整审查窗口、离线/在线参考分离及一对一五点匹配评价。

本版只跟踪**首次几何越界**。它尚未实现持仓生命周期、同向越界之后继续管理到反向退出、跨级别交接或成交记录。几何下沿被横盘价格跌出也只是几何事件，不被解释为已证明的趋势反转。用户规定的本级反向退出规则完整保留在交接需求中，没有被替换成固定止盈、第三浪平仓或自动反手。

`daily_proxy_close_1400` 是每日抽取的供应商 60m bar，`daily_proxy_close_1430` 是每日抽取的 30m bar；它们的 OHLC 不是完整日线。`daily_noon_close_1130` 按供应商午收盘视图解释。所有记录均为中证1000指数信号面，不能变成 IM、ETF 或期权的可执行价格与收益。

## 7. 合成、因果与稳定性验证

最终 Python 3.11 本地测试为 **125 passed**：核心 21、独立性质审查 18、回放/标注 25、数据工作流 9、既有契约回归 52。新增代码的 Ruff 检查通过；GitHub 完整仓库验证与同样 125 项测试也已通过。测试通过代表被检查的实现性质与契约成立，不代表真实形态准确率合格。

[合成摘要](../../cloud_results/two_wave_synthetic/summary.json) 包含 12 个固定场景。水平、稳定上涨漂移、稳定下跌漂移各生成 8 个结构，分别输出预期类别；强漂移无原价反转及常数价格生成 0 个结构。其余覆盖周期变化、幅度变化、收敛、扩张、跳跃、平台和混合尺度噪声，输出对应分类或拒判属性。独立测试另检查第五点确认前不可见、确认即越界、未来追加不重写、平台首次极值和结构年龄。

18 组真实运行的批量与逐根输出一致，每一根流式处理时已经发出的事件均与最终历史前缀一致。另按固定的短前缀、倍增长度、中点和终点独立重跑，没有发现差异。**没有声称对每一个真实前缀都从零独立重跑，也没有把 bar 序因果性当作历史实时可得性。**

[稳定性摘要](../../cloud_results/two_wave_stability/summary.json) 记录了 6 视图共 24 次配置运行，同一源数据没有改写：

## 8. 已修正的问题与可视化验证限度

实现和独立审查中完成以下修正，并保留相应测试：

1. 保存源 `available_at` 和信息时间前缀最大值，分开几何确认与真实可得性；缺字段显式标记假设。
2. 一对一匹配从局部距离排序改为最大匹配数之后全局最小总极值距离，按稳定 ID 确定消歧。
3. 主 macro-F1 纳入未检出参考的 FN 和完整审查窗内未匹配明确预测的 FP；仅匹配对象的分类指标降为辅助项。
4. 评价窗口以第五极值归属核心区间，允许前面四点处于上下文；`complete_reviewed/fully_reviewed` 明确对应。
5. 在线参考按可见截止时刻分组；相同结构的多张截图不增加独立样本数。看过未来或在其他尺度看过更晚行情后，回退标注不能继续称独立在线参考。
6. 默认盲标注隐藏算法结果；一旦显示算法，会话后续标注标明非独立。完整窗口和零散候选审查分开，避免无法发现漏检的问题。

HTML 内嵌所打包的数据，不访问外部 CDN；它能管理正常界面操作中的暴露状态，但不能阻止审查者主动读取文件源码、刷新会话或使用先前记忆。严格独立性仍依赖真实审查过程。

浏览器打开本地 `localhost/file` 的尝试被 Cloud URL policy 拒绝后已停止，没有绕过限制。已完成 JavaScript 的 Node 语法检查和 8 项曝光断言；主代理实际检查了合成图 PNG 的排版。**真实浏览器交互点按、播放和下载尚未完成验证**，不能把静态代码检查写成端到端界面验收。合成图可查看 [SVG](../../cloud_results/two_wave_synthetic/synthetic_gallery.svg)。
