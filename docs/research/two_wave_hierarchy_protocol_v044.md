# 两浪 v0.4.4：层级候选构造单组件消融协议

日期：2026-09-05。状态：**结果前冻结**。本轮只研究如何从 v0.4.3 已确认局部极值中因果地跳过子尺度摆动并形成父级五点；不改 v0.4.3 局部拐点确认核、不改 v0.4.2/v0.4.3 尺度资格、不改 D1 方向、不改有效信息时钟、不改 `(start,end]` 互斥发布。仍只使用仓库既有 2015—2020 开发行情；主视图为原生 `5m_offset_0`，其余四个原生 5 分钟偏移仅做稳健性，`1m_official` 仅诊断。无新行情、无重采样、无第三浪、无收益、无交易权限。

## 1. 为什么现在只改候选层级

v0.4.3 已删除“连续 3 根严格反向收盘”确认条件，改为对侧运行极值至少发展到冻结的 `min_leg=4` 后确认。正式结果证明这一步有价值：原 case_02 的 90/3 假第二浪被结构性禁止，跨数周 case_11/14 不再作为原单一五点出现，五个原生 5 分钟偏移相对主视图区间 IoU 也从约 11%–18% 提高到约 20%–28%。

但最大剩余瓶颈已转移到 `局部拐点 -> 相邻五点`。case_00 的大下移被 4–20 根局部摆动碎片化，中间子尺度极值阻断了父级两个完整波形，因此正确的大结构甚至没有机会进入资格判断。2019-04-15 也出现 6/5/38/7、5/38/7/4 这类明显层级错位候选。此时直接调松 `duration_ratio=2`、`min_leg_efficiency=.5` 等资格阈值会混淆问题，因此本轮禁止调整资格和 D1。

## 2. H16 的角色：继续是诊断，不偷换成父级周期参数

仓库原始需求要求“波浪尺度由事前固定算子定义”，同一 K 线周期本身不能等同于同一波浪尺度。外部研究随后明确的 `H=16, W=128` 是：每根 K 线计算过去 16 个价格变化间隔的路径效率，再观察最近 128 个 ER。仓库已有契约同时明确：H16/W128 是诊断坐标，16 **不是两浪总长**，也没有证据说明一个完整波浪或一条腿应固定为 16 根。

因此 v0.4.4 不把 H16 新增为 `parent_leg=16`、`parent_cycle=16` 或任何新的结构阈值。这样既避免把 2018-06-20 那组 11/13/15/14 四腿、24/29 两周期的候选先验杀掉，也避免把另一套“路径效率观察尺度”未经验证地偷换成“波浪周期真值”。H16/W128 仍只在图形和结果表中作为同根数诊断。

本轮父级粗化只复用 v0.4 已经结果前冻结、且一直保留到 v0.4.3 的时间尺度语法：`min_cycle=12`、`max_cycle=48`。它们原本就是“一个完整周期是否落在目标时间尺度”的资格边界。本轮只把这个既有时间语法前移到**候选粗化的闭合条件**，不新增任何可调父级参数；之后仍把形成的父级五点交给原资格函数完整复核。

## 3. 唯一新增组件：因果最小周期父级粗化

输入不是价格重新检测，而是 v0.4.3 `TemporalMaturityEngine` 已确认的局部极值流。v0.4.3 的每个局部极值发生位置、局部确认位置、`available_at` 前缀信息时钟和 epoch 全部原样保留。

对每个 v0.4.3 epoch 独立处理，高点起算和低点起算完全对称：

1. 该 epoch 第一个**非左删失**局部极值成为父级同相位锚点 `A`。左删失局部极值不进入父级周期。
2. 之后按局部极值**确认顺序**逐个处理，只使用已经确认的历史信息。
3. 遇到与 `A` 相反相位的局部极值时，维护自 `A` 以来已经观察到的**最极端对侧极值** `B`：`A` 为 low 时取最高 high；`A` 为 high 时取最低 low。若出现更极端的同类 `B`，旧 `B` 被记录为 `opposite_extreme_replaced_before_parent_close`；未成为最极端者记录为 `non_extreme_opposite_subscale`。价格完全相等时保留最早发生者，不按后续形态择优。
4. 遇到与 `A` 同相位的局部极值 `C`：
   - 若 `C.occurrence_bar - A.occurrence_bar < min_cycle(12)`，该回返被视为当前目标时间尺度下尚未成熟的子尺度完整回返，记录为 `same_phase_return_before_min_cycle`，但**不改写 A、不重置时钟、不按价格更高/更低重新择锚**。这样连续 8–10 根左右的小周期可以因果地被聚合，而不会在趋势中因为不断创新低/新高而永久重启。
   - 若 `12 <= C-A <= max_cycle(48)`，第一次满足条件的 `C` 立即闭合父级周期 `A -> B -> C`。`B` 只能是截至该时刻已观察到的最极端对侧局部极值；禁止在闭合后按腿长对称、振幅对称、D1、通道拟合、资格结果、覆盖率或任何未来收益改选内部点。除 A/B/C 外，本周期内其余局部极值全部保留在跳过账本。
   - 若第一次可用的同相位回返已满足 `C-A > max_cycle(48)`，该未完成父周期在目标尺度下超龄，不补造结构；未晋升的待定局部极值记录为 `parent_cycle_exceeded_max_cycle`，并以当前 `C` 作为新父级锚点重新开始。不得跨越该超龄失败拼接父周期。
5. 父周期闭合时，A/B/C 的**父级身份**只在 `C` 的 v0.4.3 局部确认时刻才成立。发生位置仍是各自原局部极值位置；同时保存各自原局部确认时刻和父级晋升时刻。不得把 B 在后来被选为父级中点的事实回填成 B 当时已知的父级身份。
6. 一个父周期闭合后，以 `C` 作为下一父周期的共享同相位锚点继续。连续两个父周期形成相邻五个父级极值 `A,B,C,D,E`，才产生一个 v0.4.4 候选。
7. v0.4.3 一旦发生 `max_unfinished_leg` epoch 重启，v0.4.4 活跃父级链同步断开；禁止跨 epoch 组合。

该算子只有一个新增的**算法身份**，没有新增数值参数。父级周期仍必须满足真实交替价格转折；若固定规则在某段行情无法形成父周期，输出未覆盖/未决，不强行造浪。

## 4. 明确保留不变的层

父级五点形成后，直接调用 v0.4.3 所使用的冻结 `evaluate_pair`：四腿最短 4、周期 12–48、总跨度至多 96、周期/对应腿时长比、原价去漂移振幅比、路径效率、单根跳跃、平台、交易日/墙钟跨度和确认延迟全部不改。即使父级构造使用了 12–48 作为闭合语法，资格层仍再次完整检查，不能因为“已粗化”而自动合格。

D1 仍只由三个同相位位移与原冻结阈值判断 `uptrend/downtrend/range/uncertain`；不引入 H16 ER、通道质量或层级跳过数量。主视图目前 `range=0` 是独立问题，本轮不修。

互斥发布继续使用原 `ExclusiveLedger`，按确认顺序先到先得，方向不确定但尺度合格仍占有 `(start,end]`。候选可以重叠并保留在审计层；不因层级候选更多或更少而改变发布规则。有效信息时刻继续使用原数据 `available_at` 前缀最大值，不把计算确认当成已证明盘中实时可得。

## 5. 必须保留的审计谱系

正式输出至少同时保存：

- v0.4.3 原始局部极值流；
- v0.4.4 晋升后的父级极值流；
- 每个闭合父周期的 A/B/C、本地极值 ID、发生/局部确认/父级晋升时刻；
- **全部未晋升局部极值及原因**，包括左删失、12 根以内同相位回返、非极端对侧点、被更极端对侧点替换、父周期超龄、epoch 重启遗留；
- 父级五点候选、原资格所有拒判理由、D1 分类、互斥发布与全长分区；
- v0.4.3 与 v0.4.4 的候选身份、拥有区间、方向一致性与未覆盖差异。

跳过账本的目的，是防止“层级平滑”退化为不可审计的后视手工挑点。

## 6. 因果与回归不变量

正式实现必须证明：

- v0.4.4 内部运行得到的 v0.4.3 局部极值、局部 reset 与单独运行 v0.4.3 **逐条完全一致**；否则说明本轮污染了局部确认核。
- 25%/50%/75% 固定前缀重放中，父级极值、父周期、跳过账本、候选和互斥发布只要其父级确认时刻已经落在前缀内，就必须与全量运行前缀完全一致。
- 所有父级周期的同相位 A→C 发生间隔必须在 12–48 根内；所有父级候选仍由五个真实 v0.4.3 局部极值组成，不允许插值或制造极值。
- case_02 的原 90/3 五点不得复活；任何 1–3 根局部假腿也不能通过父级层重新制造。
- v0.4.3 epoch reset 之后不得与 reset 前父级极值配对。

这些只是实现正确性，不等于形态准确率。

## 7. 正式重放最低报告项

六个既有视图同时运行冻结 v0.4.3 基线与 v0.4.4。主视图首先断言 v0.4.3 仍为正式基线 `4706 候选 / 341 尺度合格 / 212 互斥发布`，防止其他改动混入。

至少报告：

- 局部极值数、父级极值数、父周期数、被跳过局部极值数及原因分布；
- v0.4.3 相邻五点候选与 v0.4.4 父级五点候选数量、资格、互斥发布、跨度、方向分布；
- 父级候选中每个周期包含多少个被折叠的局部摆动；
- 五个原生 5 分钟偏移映射到既有 1 分钟时间戳后的区间 IoU，同时报告各视图覆盖率，禁止只用覆盖暴涨解释 IoU 改善；
- 25%/50%/75% 固定前缀因果重放；
- 固定 2018-06-20、2019-04-15、2020-07-15 窗口；
- 原 legacy case_00…case_15，重点检查 case_00、case_02、case_10、case_11、case_14。

最低形态问题仍是：case_00 是否终于出现覆盖人眼大下移的父级同尺度候选；2018-06-20 是“父级候选存在但资格路径效率误杀”还是根本无目标两浪；2019-04-15 是否因层级粗化从 6/5/38/7 之类局部错位变成可解释父级周期。case_02、case_11/14 不能为了修 case_00 而退化。

无论发布数、覆盖率或 IoU 如何变化，本轮默认状态仍为 `morphology_replication_not_yet_accepted`。只有层级候选构造本身被证明更接近“两个连续同尺度完整波形”且不引入新的明显反例，才进入下一独立实验；资格硬边界与 D1 range/trend 分类必须继续分开研究。
