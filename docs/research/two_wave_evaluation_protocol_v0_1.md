# 两浪识别评价预注册协议 v0.1

状态：`evaluation_protocol_frozen_before_real_result_review`。本协议与 `two_wave_recognition_spec_v0_1.md` 在真实识别结果审阅前固定。以下数值是**提议验收目标，尚待独立评估**，不是已获得的结果或用户曾指定的交易参数。每次运行必须记录两文档、完整配置、源码及数据的哈希；后续修订另起版本，保存变更理由和旧结果，不允许看结果后移动标准。

## 1. 参考标签与抽样单位

算法标签不能充当正确答案。标注者根据冻结的原价反转、完整周期和尺度说明独立作图；初次标注界面隐藏算法拐点、通道、分类和候选是否存在。标注身份、参考版本、完成时间、理由、置信度和复核记录必须保存。

两套参考分别建立、分别计数、分别报告：

1. **离线几何参考**：可以看完整审查窗口及上下文，标出原始价格中的拐点、完整周期、五点两浪和父分类。允许利用后续走势定位历史几何，不将这种优势伪装成在线识别能力。
2. **在线截断参考**：只能看截止时间及以前的数据，记录此时是否可识别、可识别对象及分类、最早认为足够确认的时间。以后追加信息产生新参考版本，不改写先前意见。离线标注不复制为在线真值；同一标注者若已见该样本未来，不再担任该样本盲在线标注者。

在线参考还须注明时钟：按 bar-end 截断只能检验**理想同步前缀**的算法可识别性；真实信息集视图必须同时满足 `information_available_time <= cutoff`。当前可下载 Parquet 的 `available_at` 指向当天上海时间 15:30，不能由早盘 bar-end 推断早盘已可得。缺字段时 `bar_end_assumed=True` 只是明确假设；前缀一致性、人工截断图或次 bar 对齐均不能单独证明历史 PIT、实时可用或可成交。若缺独立可得性凭据，报告须保留该缺口，不能将理想同步在线验收升级为真实交易可执行验收。

主参考从时间窗口抽样，不能只抽算法已经发现的候选，否则无法发现漏检。预先按现有 DataHub 产品身份（含频率/偏移/实际导出频率）和 2015—2020 日历年度分层，用固定种子 `20260905` 选择审查窗口；不使用收益、事件结果、分类或拟合误差决定抽样。`daily_proxy_close1400/1430` 是供应商 60m/30m 每日抽样视图，独立标识，不冒充完整日线 OHLC 产品。

默认每个产品年度先取两个不重叠的 256 根 K 线审查核心；不足时取该年度可用完整区间并记录例外。抽样起点从该层合法起点均匀抽取，保存抽样清单后才开始标注；上下文与计分核心分开。离线可加前后上下文，在线始终不暴露截止时间之后的行。额外上下文不能把跨年度价格变成运行时状态。

标注对象归入其第五极值发生点所在核心窗口。窗口必须标记 `complete_reviewed=true`，表示已检查窗口内所有符合尺度定义的参考对象，并允许明确“没有两浪”。算法确认可能晚于窗口末端，应以其五点发生区间匹配，不因自然确认延迟直接认作离线漏检；在线评估则严格限制 `confirmed_at <= cutoff`。

若样本不足，按同一种子产生的后续窗口顺序扩充全部相关层，不按算法好坏挑图。每种参考至少 200 个独立人工标注、去重后的两浪对象，且 `range/uptrend/downtrend` 各至少 30 个；离线和在线分别满足。这里“独立标注”不等于重叠行情在统计上独立，相关性见第 5 节。不能把同一五点结构的多个截图重复计数。

另建算法候选抽样集，仅用于检视误检、拒判与边界失败；必须与窗口参考分开，不能用候选审查的通过率代替召回率。代表性展示同时包含成功、错误/争议、无反转、确认滞后、确认时越界及形态拒判样本。

## 2. 固定匹配与仲裁规则

- 品种、DataHub 产品/频率、尺度规则与相位必须相同，不跨尺度或跨相位匹配。
- 两浪结构需要五个同类型极值分别在参考极值的 **±2 根该产品 K 线** 内，成员次序相同。三个极值的完整周期采用相同规则；单拐点按类型与 ±2 根匹配。
- 采用一对一匹配，先最大化可匹配数，再最小化所有对应极值绝对 bar 距离之和；仍同分时按参考 ID、算法 ID 的确定次序消歧。不得依据分类是否一致、未来收益或视觉漂亮程度选匹配。
- 匹配使用极值发生位置；确认时间单独评估延迟，不能把确认腿压缩成零延迟。离线数据尾部未能获得确认信息者单列右截断，在线没有足够信息者记为参考不可识别，不随意补作正确分类。
- 参考几何有争议、多个划分均合理、尺度理解冲突时，由第二标注者复核并记录仲裁；未解决者保留 `ambiguous`，报告数量及占比，不静默删除。主要指标用已仲裁参考，同时给出歧义对象计入/排除的影响。

必须分别记录漏检、误检、错误拆分、错误合并、两浪错误配对与尺度不一致。拆分/合并通过未匹配对象的成员与时间区间关系标记，不能用提高匹配容差把它们消失。修改 ±2 根容差只能构成新的协议版本，不能改写本版主结果。

## 3. 指标、分母与提议目标

只有 `complete_reviewed` 窗口内的算法输出才具有可审计的假阳性分母；未完整标注的窗口和只标了一个候选的截图不能用来估算全量 precision。输出数量、匹配数量、漏检数量、假阳性数量及所有排除原因，禁止只给百分比。

| 指标 | 定义/报告规则 | 本版提议目标 |
|---|---|---:|
| 波浪/两浪 precision | 一对一匹配对象数 / 完整审查范围内可计分算法对象数；周期和两浪分别报告 | ≥0.80 |
| 波浪/两浪 recall | 一对一匹配对象数 / 可计分参考对象数；周期和两浪分别报告 | ≥0.80 |
| 父分类 macro-F1 | 三个明确参考类别分别计算 F1 再平均；算法 `uncertain` 或未检出不能视为该类别正确 | ≥0.75 |
| 明确分类覆盖率 | `range/uptrend/downtrend` 输出数 / 可计分全部算法两浪输出数，含拒判/无效对象在分母 | ≥0.60 |
| 参考端明确分类覆盖 | 已匹配且得到明确算法分类的对象数 / 全部可计分参考两浪 | 必报，防止低检出率掩盖覆盖不足 |
| 拒判率与无效率 | 分别报告总数、各原因和各参考类别中的比例 | 必报 |
| 因果一致性 | 相同前缀已确认对象与事件完全一致，未来追加不重写历史 | 零差异 |

展示四类参考 × 四类预测混淆矩阵，并另加 `not_detected` 列和未匹配预测计数。主要三类 F1 中拒判和未检出构成对应类别的漏判；完整审查窗口内未匹配且给出明确类的算法结构计入其预测类别的假阳性。避免只在“已正确匹配且愿意分类”的小集合算高分；同时可给出匹配条件下分类结果，但明确它是辅助指标。参考本身 `uncertain` 单列报告，不强塞进震荡类。

延迟报告至少包括：每个极值发生到确认；第二周期末点发生到两浪可识别；在线算法确认相对在线人工最早可识别时间。按 bar 数与实际经过时间分别给出样本数、分位数（p50/p90/p95）、最大值及未确认尾部数。另报 `information_available_time` 相对 bar-end 确认的额外等待，不能隐藏供应商可得性延迟。不能用平均值隐藏长尾，也不要求算法零延迟复刻事后标签。

覆盖描述必须区分：没有足够原始反转/不足两浪的时间、形成两浪后的分类覆盖、人工参考被检出的覆盖。另报拟合边界和冻结 close 包络的覆盖率、确认时已越界比例。没有预测对象时，分母为零的比例记为不适用，不能写成 100% 正确。

离线和在线各自报告是否达到目标，不混合样本凑数。达到点估计目标但标签数、类数、盲标注、完整窗口审查或不确定性报告不足，仍不能宣布完整验收。所有目标满足也只是形态任务的证据，不代表第三浪或收益假说成立。

## 4. 实现性质与固定敏感性检查

合成样例只验证实现性质，不证明真实市场规律。至少覆盖以下参数化场景，保存构造参数、预期性质和实际断言：

| 场景 | 关键断言 |
|---|---|
| 水平、上漂和下漂周期 | 暖机排除后五点形成两个完整周期；可解释分类方向 |
| 强漂移无原始反转、常数价格 | 不造浪；不足两浪/无反转状态；不除零 |
| 同相位先升后降、收敛/扩张 | 方向冲突及形态属性不被单个 D 掩盖 |
| 周期/振幅变化、混合尺度噪声 | 同尺度仍按固定规则；不隐含等长等幅条件 |
| 长平台、跳空 | 首次同价极值规则确定；确认事件只产生一次；不假设 OHLC 内先后 |
| 第五极值未确认、随后确认且已越界 | 确认前无已知结构；确认时越界单列，不回填 |
| 流式/批量、不同前缀、未来追加 | 已确认事件、结构旧版本和 ID 一致；候选末端可变化 |

批量必须重用同一逐根引擎。合成小样本对每一个前缀检查；真实数据根据预先记录的确定前缀集合检查并报告覆盖，不能只测一个终点后声称穷举通过。比较仅取在该前缀已确认/生效的记录，排除可变候选，不能排除不利的已确认事件。

敏感性仅比较 `reversal_log ∈ {0.008, 0.010, 0.012}`，其余配置固定；不据结果选“最佳阈值”，不赋予参数选择权限。记录周期/结构数量、分类分布、匹配与标签转移、拒判及延迟的变化。

数据微扰固定在 log-price 上施加幅度 `1e-5` 的确定扰动，种子 `20260905`；同一 bar 的 OHLC 乘同一个正因子以保持合法次序。扰动是明确标识的开发稳定性实验，不改原 Parquet，也不制造新的市场历史。报告结构匹配变化、事件确认变动及分类变化，不事后改变扰动幅度以获得稳定。

## 5. 相关性、分层与不确定性

按产品/频率、固定尺度、年度和预先抽样窗口报告样本量与结果。年度只用于评价分层，不能进入运行时市场状态或构成结果驱动的日历交易规则。不得随机拆分相邻重叠结构后宣称样本外独立验证；整个 2015—2020 都是开发材料。

不确定性以时间审查窗口为 block，而不是以重叠两浪为独立抽样单位。相互重叠的窗口先合并为同一 block；跨频率同一日历窗口共享 block 身份。预定按产品/年度分层进行 2,000 次 block bootstrap、种子 `20260905`，给出指标 95% 百分位区间并报告独立 block 数。无法稳定重采样的稀疏层报告原因和原始计数，不给伪精确区间。

若当前实现尚未提供上述 CI、独立标注或仲裁工具，报告必须逐项写明“未实现/未运行/样本不足”，不能用单对象二项区间替代相关性处理并声称协议齐全。本阶段不进行第三浪显著性检验、收益优化或多重搜索。
